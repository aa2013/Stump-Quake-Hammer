# Stump Quake Hammer

饥荒单机版mod。

给锤子加上捶地用法。

锤子砸到树桩时，会把落点周围范围内的所有树桩一次性震出，各自的掉落物照常结算，不必再一个个用铲子挖。

用法：装备锤子，右键树桩。

---

dont starve mod.

Adds a ground pound to the hammer.

Smashing a stump shakes out every stump within range of the landing spot at once, loot included, so there is no need to dig them up one by one with a shovel.

Use: equip the hammer, right click a stump.
